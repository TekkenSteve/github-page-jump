Open this file directly in Chrome to exercise the injected controls against every supported pagination structure. Navigation is blocked on purpose: watch the address bar or the console output for the resolved target URL.

Page-parameter pagination (.paginate-container with page links)

Profile tabs such as ?tab=repositories carry a real page parameter but hide the numbers behind Previous / Next. The fixture serves a fake 8-page list: typing a page number jumps instantly, and the last-page control probes for the total.

Cursor pagination (.paginate-container with after links)

GitHub lists such as ?tab=stars paginate with an opaque cursor and no page numbers. The fixture serves a fake 12-page chain, so the controls index it and log every resolved URL to the console.

Last page of a cursor chain (only a before= link)

The final page of a cursor list carries no after= link at all: Previous is a before= link and Next is a disabled button. The number window must keep working here instead of disappearing.
